# Лабораторная работа №1 --- Построение и экспериментальная проверка вероятностной модели

## Описание

Проект посвящён построению и экспериментальной проверке вероятностной
модели случайного броска бумажного стаканчика.

Цель работы --- сравнить:

-   теоретические вероятности;
-   результаты физического эксперимента;
-   результаты компьютерного моделирования;

а также исследовать сходимость относительных частот при увеличении
количества компьютерных испытаний.

В качестве исходов рассматривается **первое касание стаканчиком
горизонтальной поверхности**:

-   `Дно`;
-   `Бок`;
-   `Верх`.

Последующее движение объекта после первого касания при классификации
исхода не учитывается.

## Модель эксперимента

В компьютерной модели стаканчик задаётся четырьмя вершинами трапеции.

Основные геометрические параметры:

``` text
H     = 0.13 м
R_TOP = 0.04 м
R_BOT = 0.025 м
```

Центр масс располагается на высоте:

``` text
Y_CM = 0.40 · H
```

В модели также используется коэффициент момента инерции:

``` text
INERTIA_K = 1.3
```

и ускорение свободного падения:

``` text
g = 9.81 м/с²
```

Критический угол определяется из геометрии боковой стенки:

``` text
angle_side = arctan2(H, R_TOP - R_BOT)

critical_angle = angle_side / 2
```

В используемой конфигурации критический угол составляет примерно
`41.7°`.

## Случайные начальные условия

Для каждого компьютерного броска генерируются случайные параметры.

  -----------------------------------------------------------------------
  Параметр                            Распределение / диапазон
  ----------------------------------- -----------------------------------
  Начальная высота `y0`               нормальное распределение
                                      `N(0.50, 0.05)` с ограничением
                                      `[0.30, 0.70]`

  Начальный угол `θ0`                 равномерное распределение `[0, 2π)`

  Угловая скорость `ω`                равномерное распределение
                                      `[-15, 15]` рад/с

  Горизонтальная скорость `Vx`        нормальное распределение
                                      `N(1.5, 0.3)` с ограничением
                                      `[0.5, 3.0]`

  Вертикальная скорость `Vy`          нормальное распределение
                                      `N(0.2, 0.4)` с ограничением
                                      `[-0.5, 1.0]`
  -----------------------------------------------------------------------

Для воспроизводимости результатов используется:

``` python
np.random.seed(42)
```

Всего генерируется:

``` text
N_SIM = 100000
```

испытаний.

## Расчёт движения

Вертикальное движение центра масс описывается уравнением:

``` text
y(t) = y0 + Vy · t − 1/2 · g · t²
```

Время полёта определяется как положительный корень соответствующего
квадратного уравнения.

Угловая скорость преобразуется с учётом коэффициента инерции:

``` text
ω_eff = ω / √INERTIA_K
```

После этого конечная ориентация определяется выражением:

``` text
θ_final = θ0 + ω_eff · t_hit
```

Горизонтальное смещение:

``` text
x(t) = Vx · t
```

## Определение исхода

В момент первого касания вычисляются координаты всех четырёх вершин
стаканчика.

В качестве точки касания выбирается вершина с минимальной координатой
`Y`.

Затем вычисляются углы двух сторон стаканчика относительно горизонтали:

-   стороны дна/верха;
-   боковой стороны.

Регистрация исхода выполняется по следующему правилу:

``` text
если угол дна/верха < критического угла:
    если первой коснулась вершина дна → ДНО
    если первой коснулась вершина верха → ВЕРХ
иначе:
    БОК
```

Таким образом, компьютерная модель использует то же правило регистрации
первого касания, которое применяется для классификации физического
эксперимента.

## Теоретические вероятности

В статистическом анализе используются следующие значения вероятностей:

``` text
P(Дно) = 0.22
P(Бок)  = 0.53
P(Верх) = 0.25
```

Сумма вероятностей:

``` text
0.22 + 0.53 + 0.25 = 1.00
```

Эти значения используются как теоретические ориентиры при построении
графика сходимости.

## Статистический анализ

Для каждого исхода вычисляется накопленная относительная частота:

``` text
p̂_i(n) = (1/n) · Σ 1{X_j = ω_i},
```

где:

-   `n` --- количество выполненных испытаний;
-   `X_j` --- исход `j`-го испытания;
-   `ω_i` --- рассматриваемый исход.

При увеличении количества испытаний относительная частота должна
стабилизироваться около соответствующей теоретической вероятности.

В проекте это исследуется на диапазоне:

``` text
10 → 100 → 1000 → 10000 → 100000
```

График `convergence_plot.png` позволяет визуально исследовать проявление
закона больших чисел.

Проект реализует компьютерную часть лабораторной работы:

-   строится вероятностная модель;

-   выполняется большое количество компьютерных испытаний;

В исходном задании также требуется отдельный физический эксперимент с не
менее чем `100` испытаниями и его видеофиксация. Эти материалы данным
репозиторием автоматически не создаются.

## Ограничения модели

Компьютерная модель является упрощённой и не претендует на полное
физическое моделирование движения стаканчика.

В частности, используются заданные распределения начальных параметров и
геометрическое правило классификации первого касания. Реальные эффекты,
связанные с материалом объекта, деформацией, сопротивлением воздуха,
трением, взаимодействием с поверхностью и последующим движением, в
данной модели не моделируются.

Поэтому различия между теоретическими вероятностями, физическим
экспериментом и компьютерным экспериментом следует интерпретировать с
учётом этих допущений.
